This is an Anglicised fork of the excellent Freecell game found here: https://github.com/kenjinote/FreeCell
No fancy bells or whistles, just plain Freecell.  The original was/is in Japanese.

I have converted all the menus to US English and also added a high-res card set and made the main program window resizable.  The window contents and cards also resize with the main window unlike the original program.  The cards have also been embedded into the binary so there's no need to distribute the original 52 SVG files.  As such, just copy the binary anywhere on your Windows PC and run it from there.
